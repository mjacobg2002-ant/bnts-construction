# BNTS Construction LLC — Website

Single-page marketing site for **BNTS Construction LLC**, a Class A licensed foundation, structural concrete, stamped patio, hardscape and addition contractor serving Northern Virginia (Herndon, VA).

- **Tech:** static single-file `index.html` (no build step)
- **Assets:** real project photos + logo in `/images` (sourced from bntsconstruction.com)
- **Hosting:** GitHub Pages

## Local preview
Open `index.html` in a browser, or run:
```
python3 -m http.server 8000
```

## Content
All copy, testimonials, license number (#2705172992) and contact details are taken from the live business site.
